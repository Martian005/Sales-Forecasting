# Sales Forecasting

Walmart Sales Analysis and Forecasting — a Python mini-project covering core language concepts, data analysis, statistics, and machine learning on real Walmart weekly sales data.

## Features

Menu-driven CLI covering:

1. Python Core Concepts
2. Data Structures
3. Python Libraries
4. Custom Modules
5. Exception Handling
6. Web Scraping
7. File Handling
8. CRUD Operations
9. NumPy
10. SciPy
11. Pandas
12. Data Preprocessing
13. Data Visualization
14. Statistical Analysis
15. Probability
16. Sampling & Inference
17. Hypothesis Testing
18. Machine Learning (Linear Regression sales prediction)

## Dataset

`Walmart_DataSet.csv` — weekly sales records across 45 stores with columns:
`Store, Date, Weekly_Sales, Temperature, Fuel_Price, CPI`

## Setup

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

Pick an option (1–19) from the menu to run that module.

## Project Structure

```
main.py               # menu + all 18 topic functions
analytics_module.py   # custom module (avg sales, sales category)
Walmart_DataSet.csv   # dataset
requirements.txt      # dependencies
```
